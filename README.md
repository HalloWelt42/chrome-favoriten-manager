# FavGrid v3.4.0 - Premium Speed Dial

Ein eleganter, hochgradig anpassbarer Speed Dial mit Glassmorphism-Design für Chrome und Chromium-basierte Browser.

## Features

- **Glassmorphism Design** - Moderne, halbtransparente UI mit Blur-Effekten
- **Responsive Layout** - Passt sich automatisch an die Bildschirmgröße an
- **Design-System** - Dark, Light und System-Modus
- **20 Akzentfarben** - Material Design Farbpalette
- **Hintergründe** - Gradienten, Farben oder eigene Bilder (Dark/Light separat)
- **Gruppen** - Favoriten in Kategorien organisieren mit Drag & Drop
- **Gruppen-Manager** - Favoriten zwischen Gruppen verschieben, Mehrfachauswahl
- **Sofortsuche** - Favoriten durchsuchen oder URLs direkt eingeben
- **Sortierung** - Nach Name, Datum, Besuche oder manuell
- **Tastaturkürzel** - 1-9 für Schnellzugriff, / für Suche
- **Drag & Drop** - Icons per Maus sortieren
- **Import/Export** - JSON, HTML, CSV, OPML, Markdown, URL-Listen
- **Intelligentes Favicon-System** - 50+ Quellen mit HTML-Parsing
- **Icon-Bearbeitung** - Weiß entfernen, eigene Bilder, Emoji-Icons
- **Mehrsprachig** - Deutsch und Englisch (automatisch nach Browsersprache)
- **100% Lokal** - Keine Cloud, kein Tracking, keine externen Dienste

## Einstellungen

### Erscheinungsbild
- Akzentfarbe (20 Material Design Farben)
- Hintergrund (Farbverlauf, Farbe, Bild)
- Glassmorphism (Transparenz, Weichzeichner, Rahmen, Schatten)
- Seitenübergänge (Gleiten, Überblenden, Keine)

### Raster-Layout
- Spalten (3-8), Zeilen (2-5)
- Icon-Größe (48-128px)
- Abstand und Container-Rundung
- Separate Bild-Rundung für Favicons
- Icon-Hintergrund (Farbe, Transparenz je Design)

### Beschriftungen
- Position (über/unter dem Icon), Schriftgröße, Schriftart
- Farbe separat für Dunkel-/Hell-Modus
- Eigene Schriftfamilie möglich

### Suche
- Konfigurierbare Suchmaschine (URL mit %s-Platzhalter)
- Sofortsuche ein/aus

### Navigation
- Tastatur (Pfeiltasten), Mausrad, Swipe/Trackpad
- Navigations-Pfeile ein/aus
- Klick-Verhalten (neuer Tab / aktueller Tab)
- Startverhalten (letzte Gruppe / Standard-Gruppe)

### Daten & Backup
- Komplettes Backup (JSON mit allen Einstellungen)
- 6 Export-Formate für Favoriten
- Import von HTML-Lesezeichen und JSON
- URL-Listen Import/Export
- Gruppen-Reihenfolge per Drag & Drop

## Berechtigungen

| Berechtigung | Zweck |
|---|---|
| `storage` | Lokale Speicherung von Lesezeichen und Einstellungen |
| `activeTab` | Aktuelle Seite als Lesezeichen hinzufügen |
| `tabs` | Tab-Titel für neue Lesezeichen auslesen |
| `contextMenus` | Rechtsklick-Menü "Zu FavGrid hinzufügen" |
| `notifications` | Bestätigungen beim Hinzufügen |
| `alarms` | Auto-Backup |
| `search` | Suchmaschinen-Integration |

## Datenschutz

FavGrid speichert alle Daten ausschließlich lokal in deinem Browser. Keine Daten werden an externe Server übertragen. Kein Tracking, keine Analyse, keine Werbung.

2. "Entwicklermodus" aktivieren
3. "Entpackte Erweiterung laden"

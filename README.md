# FavGrid v3.0.0 – Premium Speed Dial

Ein eleganter, hochgradig anpassbarer Speed Dial mit Glassmorphism-Design für Chrome und Chromium-basierte Browser.

## Features

- 🎨 **Glassmorphism Design** – Moderne, halbtransparente UI mit Blur-Effekten
- 📱 **Responsive Layout** – Passt sich automatisch an die Bildschirmgröße an
- 🌙 **Theme-System** – Dark, Light und System-Modus
- 🎨 **20 Akzentfarben** – Material Design Farbpalette
- 🖼️ **Hintergründe** – Gradienten, Farben oder eigene Bilder (Dark/Light separat)
- 📂 **Gruppen** – Favoriten in Kategorien organisieren
- 🔍 **Instant-Suche** – Favoriten durchsuchen oder URLs eingeben
- ⌨️ **Tastaturkürzel** – 1-9 für Schnellzugriff, / für Suche
- 🖱️ **Drag & Drop** – Icons per Maus sortieren
- 🔄 **Import/Export** – JSON, HTML, CSV, OPML, Markdown, Text
- 🌐 **Intelligentes Favicon-System** – 50+ Quellen mit HTML-Parsing
- 🖼️ **Icon-Bearbeitung** – Weiß entfernen, eigene Bilder, Typ-Badge
- 🔒 **100% Lokal** – Keine Cloud, kein Tracking, keine externen Dienste

## Einstellungen

### Aussehen
- Akzentfarbe (20 Material Design Farben)
- Hintergrund (Gradient, Farbe, Bild)
- Glassmorphism (Transparenz, Blur, Rahmen, Schatten)

### Grid
- Spalten (3-8), Zeilen (2-5)
- Icon-Größe (64-160px)
- Abstand und Eckenradius
- Separate Bild-Rundung

### Labels
- Position, Schriftgröße, Schriftart
- Farbe separat für Dark/Light Mode

### Navigation
- Tastatur, Mausrad, Swipe/Trackpad
- Navigations-Pfeile ein/aus

### Daten
- Auto-Backup
- 6 Export-Formate
- Gruppen-Reihenfolge per Drag & Drop

## Datenschutz

FavGrid speichert alle Daten ausschließlich lokal in deinem Browser. Keine Daten werden an externe Server übertragen. Kein Tracking, keine Analyse, keine Werbung.

➡️ [Vollständige Datenschutzerklärung](PRIVACY.md)

## Installation

### Chrome Web Store
Direkt aus dem Chrome Web Store installieren.

### Manuell (Entwicklermodus)
1. `chrome://extensions` öffnen
2. „Entwicklermodus" aktivieren
3. „Entpackte Erweiterung laden"
4. Diesen Ordner auswählen
